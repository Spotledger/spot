Desktop: Alt, T, P opens Transactions → Procurement; R invokes Receive Goods. Arrows navigate, Enter opens or invokes, Escape returns one menu level. Launcher: arrows select, Enter invokes, Escape restores focus. Dialogs trap Tab focus and Escape cancels. AltGr is never captured.
