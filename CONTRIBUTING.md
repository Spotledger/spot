# Contributing

**This project does not accept external contributions.**

Spotledger Runtime is developed by Spotledger (SMC-PRIVATE) Limited in a private repository, and this repository is a periodically synchronised public copy. For that reason:

- Pull requests are restricted to collaborators. A pull request from anyone else cannot be opened, and we will not review or merge one.
- Issues and discussions may be switched off. Where they are on, treat them as one-way reports: we may not answer them, and we do not promise fixes or timelines.
- Security reports are welcome and handled separately. See [SECURITY.md](SECURITY.md).

## What you can do

The source is licensed under [Apache-2.0](LICENSE), so you are free to read it, run it, fork it, modify it and build on it, under the terms of that licence. If you fork it, please follow [TRADEMARKS.md](TRADEMARKS.md) so your fork is not mistaken for the original.

## Why

We want the runtime's design to stay coherent while it is being built, and we cannot review outside contributions to a codebase that changes this quickly. This may change later; if it does, this file will say how.
